# 可信卫士会话栏体验改造设计

## 背景

可信卫士当前采用左侧会话历史、中间对话、右侧任务状态与执行轨迹的三栏布局。此次改造借鉴 ChatGPT 清晰、低干扰的会话管理体验，但保留可信卫士的安全产品视觉与右侧任务监控，不复制与项目无关的功能。

## 目标

- 让会话栏的层级、搜索和管理操作更直接。
- 支持将会话栏收成窄图标栏，为对话区释放空间。
- 支持按标题快速查找最近会话。
- 支持跨刷新、重新登录和设备持久保存会话置顶状态。
- 保持现有对话流、任务执行、Markdown、思考状态和执行轨迹行为不变。

## 非目标

- 不增加消息全文检索。
- 不增加语音、联网搜索、插件入口或快捷指令。
- 不重构任务执行和右侧监控模块。
- 不抽象通用聊天系统。

## 界面与交互

### 会话栏

展开状态保持约 260px 宽。顶部左侧显示“可信卫士”，右侧依次提供标题搜索和收起按钮。收起后变为约 56px 的窄图标栏，保留展开、新建会话和搜索入口；中间对话区自动使用释放的空间，右侧监控栏继续常驻。

会话列表首先显示置顶分组，其余会话继续按今天、昨天、最近 7 天和更早分组。置顶会话按最近置顶时间排序，普通会话按最近更新时间排序。

每条会话的更多菜单统一采用“左侧图标 + 右侧文字”的形式，包含：

- 重命名
- 置顶或取消置顶
- 删除

不增加复制、分享、归档等未提出的操作。

### 搜索弹窗

点击搜索图标后，在屏幕中央打开带遮罩的弹窗并自动聚焦输入框。输入为空时展示现有接口返回的最近会话；输入文字后，对会话标题进行不区分大小写的即时匹配。

点击结果切换到对应会话并关闭弹窗。点击遮罩或按 `Esc` 关闭弹窗。搜索只处理前端已加载的最近 50 条会话，不增加后端搜索接口。

### 视觉原则

沿用项目现有深色安全产品主题、青色强调色、盾牌标识和任务状态色。借鉴 ChatGPT 的紧凑信息密度和操作位置，但不复制其品牌、图标组合、文案或无关入口。

## 数据模型与接口

会话摘要增加：

- `pinned: boolean`，默认 `false`。
- `pinnedAt: string | null`，未置顶时为 `null`。

现有会话更新接口继续使用 `PATCH /v1/conversations/{conversation_id}`，请求可包含 `title` 或 `pinned`，至少提供一项。置顶时由服务端记录当前 UTC 时间；取消置顶时清空置顶时间。接口返回被更新的目标会话摘要。

Gateway 保持现有透传方式，不增加新路由。前端 API 类型和更新函数扩展置顶参数。

## 存储行为

- MySQL 会话表增加兼容字段 `is_pinned` 和 `pinned_at`，启动时沿用现有轻量迁移方式补列。
- 内存、Redis、MySQL 及组合存储对重命名、置顶、取消置顶和删除提供一致行为。
- 列表排序统一为：是否置顶降序、置顶时间降序、更新时间降序。
- 所有更新与读取继续按 `actor_id` 隔离，用户不能影响其他用户的会话。

## 前端状态与失败处理

会话栏展开状态只保存在当前页面状态中，不增加新的用户偏好配置。搜索弹窗复用现有会话列表，不维护第二份服务端数据。

重命名、置顶或删除成功后刷新会话列表。请求失败时保留原状态，并在会话栏或搜索弹窗中显示简短错误。删除当前会话成功后进入新会话；删除失败时继续停留在当前会话。

## 验证标准

- 展开、收起会话栏时，中间对话区正确伸缩，右侧监控栏保持常驻。
- 搜索弹窗默认展示最近会话，并且只按标题筛选。
- 会话菜单的三项操作均显示图标与文字，置顶项能切换为取消置顶。
- 置顶状态在刷新、重新登录和换设备后仍可从服务端恢复。
- 置顶、取消置顶、重命名和删除在所有支持的存储模式下行为一致。
- 用户数据隔离、目标会话更新返回值和不存在会话的错误响应均有测试覆盖。
- 前端构建通过，相关 Supervisor 与 Gateway 单元测试通过。
